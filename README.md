`Project Name & Description`
This project's name is Forge & Flow. It is a gym app where one can track his daily workout. Also can plan what he want to do next.
Forge is stand for hard working for shaping something, and Flow is for working naturally and smoothly. As it is a exercise app this name refer to combine strength with mobility. 
Also used light-coral (#f44369) and deep indigo (#3e3b92) color.These colors are energetic and high contrast.This color combination will draw attention to accents or call-to-action elements.

`Technology`
First of all I would like to say about Gemini. Most of the design part I took help from gemini.
also used-
1. Next.js
2. Typescript
3. DaisyUI etc.

`Key Features`
 1. So many option to choose.
 2. Details description of equipment, where it works and all.
 3. Help to keep track of burned calories.
 4. Visualization of time and burned calories.
 5. save for later.
